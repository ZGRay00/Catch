# PokéCatch 自动助手

适用于 [PokéCatch](https://pokecatch-online.app/) 的 Tampermonkey 用户脚本。当前版本 **8.3.0**。

[安装 / 更新脚本](https://raw.githubusercontent.com/ZGRay00/Catch/main/pokecatch-helper.user.js) · [CDN 备用安装](https://cdn.jsdelivr.net/gh/ZGRay00/Catch@main/pokecatch-helper.user.js) · [完整压缩包](./releases/pokecatch-helper-v8.3.0.zip) · [使用说明](./使用说明.txt) · [源码与构建](./pokecatch-helper/README.md)

8.3.0 · 传说目标支持自定义挑战顺序。昼夜、月相或每周形态轮换暂未开放时先刷后续目标，优先目标开放后回头挑战。缺少前置条件时继续补齐。已核对当前游戏包的孵蛋和靛莓果规则。

8.2.11 · 普通战斗和助手已接管的传说战期间可收成熟蛋、领取地下归队奖励。每次收蛋前先检查下一枚自然蛋是否需要靛莓果，领取完成后返回原页面。

8.2.10 · 任务运行、暂停或由同账号另一标签页接管时均可编辑队列。刷新后等待游戏确认本页控制权再续跑。自动收蛋前先检查下一枚自然蛋，需要靛莓果才闪时先确认喂果生效。

8.2.8 · 自动喂靛莓果支持对战塔和异色团体战。下一枚自然蛋需要喂果才闪时，助手进入培育屋喂果，核对库存和蛋号后返回原页面。

8.2.7 · 目标练级、通关日常和等待捕捉天气时均可勾选练级成员。队列保存具体成员；自动配队保留目标，并按其可获得的经验选图。

8.2.4 至 8.2.6 · 优化洛托姆及家电形态的搜寻路线。异色家族已满时保留成熟闪蛋并提示。刷传说前置道具时，遇到战斗或游戏选项会先返回冒险结算，再判断是否重开地图。

8.2.3 · 刷取光明石、现形镜、断牙等道具时，本轮已无目标拾取点就重开当前地图。同图多个前置道具一起检查，战斗和弹窗优先结算。

8.2.2 · 途中提前复核目的地配队。刷道具时显示选图和退避原因，收益接近时保留原队。「运行实况」增加同图队伍实绩、盒子金币收益榜和游戏厅收支。

8.2.1 · 最小化后默认只显示中心状态栏。在「设置」开启「最小化是否显示额外信息」即可显示停机记录、孵蛋、地下、队列和收益等提示。

8.2.0 · 冒险配队复用后备出场顺序、同一组成员的覆盖分及跨轮交手数据，缩短大盒子的完整复核等待。导出诊断可查看复核进度和重新计算的原因。

8.1.9 · 冒险配队按当前地区可出战的数量预留 60 至 120 秒启动时间，复核有新进展时自动续时，单次上限 15 分钟。运行状态显示当前轮次和已复核的候选数。

8.1.8 · 道具任务卡显示目标刷取量、当前持有量和本项已刷取量。相同道具的队列任务分别计数。

8.1.7 · 指定道具按预计每小时掉落量选图。各候选地图均有至少两轮样本后，统一使用实测平均用时。单轮零掉落不会压低该图排名。

8.1.6 · 指定道具刷断牙时直接前往合众「喷射徽章」的吹寄洞穴，跳过关底补练并清理残留的联盟循环。刷新续跑时也会跳过旧版保存的断牙地图补练。

8.1.5 · 收起的迷你条可拖到距右边缘 6 像素处。状态文字缩短或快捷按钮消失后，仍保持贴边。

8.1.4 · 启用「刷新后自动恢复未停止的任务」后，助手遇到游戏更新弹窗会保存进度并重新加载，读到同一账号的兼容存档后继续当前任务。

8.1.3 · 「传说目标」的「全选」旁新增「取消」，可一次清空所有地区的目标，包括搜索时隐藏的项目。刷新后会保留空选，可重新勾选或全选。

8.1.2 · 原生详情的「家族」按钮跟随游戏配色，按名称、普通或异色和等级区分持有个体。窄屏上按钮自动换行，较长的进化链可左右滑动。

8.1.1 · 在「图鉴 → 路线对比」选定路线后，可并排比较两只宝可梦的首击输出、命中率和满血耐久。点 A 或 B 可查看该个体的禁招建议。当前游戏版本的规则待核对时，列表顶部提示一次，并按上次核对的规则继续列出候选和理由。

本次更新也包含 8.0 系列的启动修复、面板与大盒子配队性能优化，以及运行诊断、实测掉落和触屏界面改进。

7.2.3 · 适配已核对的新版孵蛋、合众普通遇敌表、团体战首领参数和对战塔阶级，对战塔显示目标层难度与蛋奖励楼层。

7.2.0 · 刷钱、练级和补练完成选图与配队后沿用方案，战败或任务条件变化时复评，继续记录整轮金币和经验。刷图配队兼顾主力伤害余量、承伤与替补战力，保留指定学员。立即恢复会复用仍有效的计算结果，换队逐步核对游戏回执。

7.0.4 · 已复核的刷钱阵容优先切图并确认实际出战。普通刷钱先检查现有战力，只有需要时才安排补练。

7.0.3 · 刷钱逐图产出阵容预估，后台刷新保留有效结果。持续核查已选专用阵容，明确区分复核和等待战斗结算，并减少大盒子重复计算。

7.0.2 · 冒险配队优先解决关键战风险，复核全盒合法候选并试算互补的双人组合。

7.0.1 · 将基础刷钱排名与专用阵容评估拆开，纳入已发现的游荡首领风险。

7.0.0 · 本地共享盒子索引，分片复核配队及地图收益。整轮实测需确认到图和出战阵容；经验按指定学员目标记录。详见 [验证说明](./pokecatch-helper/docs/7.0.0-local-validation.md)。

## 安装和更新

1. 在浏览器中启用 Tampermonkey，打开上面的脚本链接并确认安装。
2. 进入游戏或刷新游戏页，确认助手面板显示 `5.3.4`。
3. 后续点击面板顶部“在线更新”。发现新版后再次点击“安装新版”，在油猴确认安装，完成后刷新游戏。

从旧版手动复制安装的用户，需要先安装这一次新版。脚本也配置了油猴原生 `@updateURL` 和 `@downloadURL`。

更新按钮优先校验 GitHub 最新提交中的完整脚本，并打开同一提交的安装链接。检查失败可重试；检查和下载不会执行远程代码，不会清空当前任务或游戏存档。
