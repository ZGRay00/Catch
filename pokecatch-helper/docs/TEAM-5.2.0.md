# 5.2.0 冒险配队验收

## 基线和预算

对象是 5.1.4 的冒险配队入口，以及同一入口的 5.2.0 实现。三组人工盒子分别有 18、90、300 只，位于合众冠军之路，原队六只的等级按玩家案例设置，其余成员均为 70 级。盒子额外放入了可检验覆盖和重复的不同种类，不能用这些成员推断玩家实际拥有的阵容。

改动前的首轮基线发现，小盒子整次同步搜索最长占用 14.21 ms，大盒子即使命中全部独立对局行，重复评估近似阵容的中位时间仍有 95.95 ms。因此先复用同节点天气、压缩对局行，保留同种战斗参数下的首选 UID，再筛选单挑候选和逐敌对策。每种属性可以保留多个成员。没有增加搜索层数或引入 Worker。

冒险搜索的目标片长为 4 ms，观测到超过 8 ms 的片段后将后续目标调至 3 ms。每轮累计计算预算通常为 180 ms，低配置为 80 ms。低配置候选初筛保留前 16 名，普通配置为 32 名，另保留逐敌对策、队内成员及锁定学员。预算届满后交还已评估的合法阵容。条件相同可以在 5 秒后从断点续算；期间允许正常任务继续。完成的计划按配队相关状态复用。缓存最多保留 4 个对手环境，每个环境最多 1,024 行。

## 已核对的游戏规则

- 公开启动文件标识为 `1125894b9a`，核对的客户端文件为 `app.0a7dcb2280.js`。84 章节的规划数据通过离线重建比对。野外威胁按原生遭遇池占比、路段野怪数及随机训练家的预计队员数加权，固定训练家每名敌人计 1，馆主计 3。后两者是助手的规划权重。助手换人开启时，单独导出的野生权重使同种同级的随机训练家敌人不会被当作单只野怪。[游戏启动文件](https://pokecatch-online.pages.dev/boot.js) · [游戏客户端](https://pokecatch-online.pages.dev/bundle/app.0a7dcb2280.js)
- 按游戏的可用招式、原生选招和命中规则估值，包括未命中后下一击必中、多段伤害与逐击取整。原生比对共 9,762 项，其中包括 2,888 个实际选招。原生自动出场依据对在场敌人的属性优先级，平分时偏好已出场者，再按队序。关闭后保留队序，助手另按实战换人开关评估可确认的普通单敌野战；实时动作还检查敌方身份、余敌、血量和战场控件。
- 普通治疗点同步计划队伍与行进队伍，回复满血并清状态；回复树果事件恢复最多 25% 最大 HP。模型估算主力在两次治疗间的磨损，兼顾平均效率、最差对局及馆主续航。当前实现按敌组聚合，未逐节点重演治疗顺序、多人对战或整场随机过程。

## 性能对照

Windows 桌面 Node 24，同一批输入，每种规模每版 11 组冷、热配对。每组清空对局缓存后跑一次，再新建引擎复用热缓存。墙钟时间包含主动让出执行权和计时器延迟；最长片段单独计量入口、回调和结果消费。同一状态再调度一次应新增 0 个计算回调。内存是显式 GC 后保留的堆差中位数，不含浏览器渲染内存和瞬时峰值。表中数字依次为 5.1.4 → 5.2.0，耗时单位为 ms。

|---|---|---|---|---|---|---|
| 18 | 9.98 / 12.82 → 38.70 / 64.44 | 1.96 / 3.39 → 16.25 / 17.89 | 12.75 → 4.20 | 3.38 → 4.01 | 0 / 18 | 0.62 → 0.37 |
| 90 | 68.54 / 109.76 → 95.16 / 118.96 | 28.12 / 31.00 → 18.24 / 30.77 | 9.34 → 4.59 | 6.06 → 4.12 | 0 / 89 | 2.65 → 1.81 |
| 300 | 305.65 / 359.77 → 316.90 / 430.75 | 166.87 / 234.72 → 47.92 / 93.16 | 7.61 → 5.50 | 6.86 → 4.15 | 0 / 297 | 8.75 → 5.99 |

小盒子的热规划原本即可在几毫秒内结束；新增让步会增加总等待。中、大盒子的热规划缩短，三种规模的冷规划墙钟 P95 均有所增加。正常点击、滚动和游戏画面的整机表现还受浏览器、实际设备和现场战斗动画影响。

桌面无头 Chrome 再以 4 倍 CPU 降速、4 个逻辑核心独立复测。每个规模每版 5 次冷启动，记录实际事件循环回调和动画帧间隔。以下是五次中观测到的最大值。

## 阵容对照

两版结果均用同一套逐敌出场和伤害计算器复核，原生自动换人开启。下表的回合与倒下数均为估算；馆主列只取标记为关键战的三名敌人。

| 盒子 | 加权平均回合 | 最差回合 | 每战平均倒下 | 关键敌人平均回合 |
|---|---|---|---|---|
| 18 | 1.515 → 1.515 | 3.327 → 3.327 | 0 → 0 | 1.479 → 1.479 |
| 90 | 1.521 → 1.521 | 2.255 → 2.255 | 0 → 0 | 1.855 → 1.855 |
| 300 | 1.222 → 1.180 | 5.727 → 2.400 | 0.000694 → 0 | 1.152 → 1.176 |

对原始六只单独做移除实验，拿掉始祖大鸟后平均回合增加 0.074，拿掉地幔岩后平均回合变化小于 0.001。这个结论限定在该地图、该队序和原生换人开启的条件下。小盒子中两版都保留始祖大鸟。大盒子新版在最差对局上的收益伴随关键敌人平均回合小幅增加。运行实况面板显示同属性队员移除后的模型分差；该指标与这里单独统计的回合差含义不同。

## 复现

从工作区根目录运行。将 `OLD.user.js` 换成本地 5.1.4 安装文件。浏览器对照使用全新临时配置，只在空白页评估合成数据。设备降速测试加速了两次预算窗口之间的虚拟游戏时钟，实际安装后会等待相应的重评间隔。

```text
node --expose-gc pokecatch-helper/tools/benchmark-team.cjs OLD.user.js 11
node --expose-gc pokecatch-helper/tools/benchmark-team.cjs Pokecatch自动助手.user.js 11
node pokecatch-helper/tools/benchmark-team-browser.cjs OLD.user.js Pokecatch自动助手.user.js
node pokecatch-helper/tools/test.cjs
node tests/pokecatch-helper-browser.cjs
node tests/pokecatch-chapters-native.cjs PATH_TO_PUBLIC_BUNDLE
node tests/pokecatch-combat-native-v400.cjs PATH_TO_PUBLIC_BUNDLE
```
