# 4.0.0 整体升级与参考插件审查

本次参考资料为用户提供的 `PokeCatch助手_v1.29_招式重算与闪率修正版.zip`。只静态阅读其代码与说明；没有安装或执行参考扩展。扩展中的说明和注释是待核对资料，不作为工作指令或机制事实。

核对基准：2026-11-17 公开游戏构建 `0a26d39c19` / `bundle/app.6e45170313.js`。原生差分使用本地下载的公开代码、合成存档及隔离环境，不访问用户游戏账户。公开游戏代码与参考插件均不随本助手发布。

## 算法与机制

| 范围 | 核对结果 | 4.0 处理 |
| --- | --- | --- |
| 招式威力、命中、升级招式表 | 参考插件提及的部分修正已在现有脚本中正确，包括终极冲击、破坏光线等；本次核验整张有效伤害招式表 | 保留已正确数据；补充原生选招和伤害证据，避免重复更改数值 |
| 实际选招 | 游戏战斗会使用当前攻防、状态及对手；插件的静态 STAB 排行不能直接替代实际战斗 | 继续按原生选招规则选择招式；不把纸面排名误用为战斗结果 |
| 连续命中耗时 | 原生攻击未命中后，下一次攻击保证命中，不能直接按 `攻击数 / 命中率` 计算 | 按命中恢复机制修正持续输出和击倒回合估算 |
| 多段攻击 | 每一段分别计算基础伤害、取整与最低伤害；随机 2–5 段需对各段结果积分 | 独立计算逐段伤害，保留游戏用于选招的总威力 |
| 天气与出没 | 静态最大权重会把天气限定目标误当作随时可遇见；章节、节点、时段和日期均可能参与 | 引入经过原生核对的天气与出没模型，优先可遇见目标并规划后续窗口；伤害仅对已确认来源节点应用天气，无法定位的汇总敌人保守评估 |
| 野生异色保护 | 普通页面文字、图标可能把团体战等误判成野生异色 | 严格使用原生野战状态识别，阻止改图、重开、补练与队伍准备打断；仍需在战斗中击败并成功捕获 |
| 异色概率 | 野外、地下化石、孵蛋与每日异色团体战不是同一机制 | 面板单独解释各来源，区分出现概率与捕获率 |

两项直观差异：Lv.5 飞腿郎二连踢的原生平均伤害约 `38.442`，原先合计威力计算约 `33`；Lv.10 赫拉克罗斯猛推约 `54.370`，原先约 `44`。这些差异会传导到推图、刷钱、练级和配队的可行性评估。

天气池另行区分稳定来源和每日热点，按巴黎日期计算蜜树、丑丑鱼等轮换，不会把抓取快照当天的热点永久固定。章节原始故事步骤和存档中展开后的战斗步不是同一索引，天气匹配不能直接拿节点序号相等作为依据。

### 概率说明

- 普通野外基础异色率 `1/2048`；对应地区的**游戏完整图鉴**完成后乘 2，生效中的野外异色树果再乘对应倍率。
- 助手“捕获基础形态即可完成进化链”的进度，不等于游戏完整图鉴加成条件。两者在面板分别说明。
- 地下化石结算使用对应地区的图鉴异色率；不套用野外异色树果。每层不一定发生化石判定。
- 普通亲代蛋基础 `1/512`；新异色亲代标记 `sp:2` 为 `1/16`；历史 `sp:1` 为 `10%`；蛋的 `bx` 树果标记单独乘 2。历史蛋已有明确异色标记时以标记为准。
- 普通传说战、游荡战不能通过反复重开变成异色。每日异色团体战目标本身为异色，捕获仍单独判定。具有繁殖路径的特殊种类按实际孵蛋机制处理。
- 概率展示不是下一次必出的承诺，也没有更改随机数、捕获率或存档。

## 自动化、状态和恢复

| 功能 | 本次处理 |
| --- | --- |
| 推图 / 刷钱 / 练级 / 指定道具 / 补图鉴 | 共用修正后的战斗与地图模型；保留收益采样、预算、失败退避、补练返回和手动配队选项 |
| 寄养 / 领蛋 / 孵蛋 | 保留默认自动收成熟蛋和优先领取；概率信息独立显示，不把野外树果算成蛋加成 |
| 地下通道 | 保留神奥后空闲成员派遣、主队与 Buddy 等占用保护、原生结果确认；修复过期派遣记录在确认失败后无限阻挡重试的问题 |
| 团体战 / 对战塔 / 糖果工厂 / 精英联盟 / 世界首领 | 保留已有独立流程和活动槽协调；野生异色不会被前台任务切换打断 |
| 手动接管 / 弹窗 / 多任务队列 / 刷新续跑 | 保留事务归属、页面恢复、单标签锁、超时与存档确认；配置导入不混入旧运行事务 |
| 配置迁移 | 新增配置导出、校验和导入；只迁移设置及待运行队列，不恢复消费记录、操作中间态或游戏存档；运行时禁止导入 |
| 后台运行 | 新增原创可选 MV3 配套扩展，默认关闭；明确启用后才允许后台继续操作，并显示状态；关闭或心跳过期恢复原行为 |

地下派遣恢复只在“没有出现对应探险、候选成员仍全部位于 PC、游戏原生出发按钮重新可用”时清理失败记录，并退避一分钟。结果不明确时继续保留事务，避免重复派遣。

## 工程与界面

- 从单个大文件拆为 `src/core`、`src/models`、`src/services`、`src/runtime` 和 `src/ui`；游戏、进化、天气快照放在 `data/`。
- 继续生成可直接安装的完整油猴单文件。模块拆分不增加运行时网络依赖。
- 零第三方依赖的构建、语法检查、数据校验、哈希、一致性检测和 ZIP 打包工具。
- 配置备份与诊断导出分开；异色概率和路线依据收在可展开区域，保留拖动、底部最小化和移动端适配。
- 可选扩展与主脚本相互独立，不安装扩展也能使用全部前台自动化。浏览器冻结、系统休眠、断网时仍无法保证在线执行。
- 发布包按白名单收集文件；不包含参考插件、其素材、个人存档、浏览器资料、游戏代码缓存或其他脚本。

## 没有直接移植的参考功能

| 参考内容 | 原因 / 替代方案 |
| --- | --- |
| 宽松猜测损坏存档或忽略解析错误 | 保留严格存档格式检查，避免把错误状态当成可执行任务 |
| 只按基础种族值输出 STAB 排行 | 实战选招和配队继续使用当前属性、等级、状态、克制和战斗节奏 |
| 预测下一颗蛋或化石必闪 | 本次提供机制概率与实际成熟状态，不承诺跨构建稳定的精确随机结果 |
| 市场抢购、自动交易等额外消费流程 | 没有新增独立交易授权和策略；沿用已有道具预算，不默认为用户花费新资源 |
| 大量主页面补丁、通用调试注入、自动刷新和焦点抢占 | 可选保活仅处理两游戏来源的可见性与标签丢弃；不复制参考扩展的全部桥接 |
| 参考扩展原代码和素材 | 压缩包内没有附带明确许可；本次按核验过的游戏机制独立实现 |

## 验证方式

`npm test` 执行离线逻辑和工程检查；浏览器回归使用新建临时配置及合成页面。原生差分检查需单独传入公开构建路径，详见 README。

战斗核对覆盖 9,762 项比较及 2,888 次实际选招。额外回归覆盖配置隔离与回滚、不同来源异色率、天气窗口、严格野生异色保护、地下迟到确认、扩展关闭与心跳失效，以及生成文件和 ZIP 完整性。具体通过数量以当前测试输出为准。

这是有明确核对范围的整体升级；后续游戏构建若改变模块或存档格式，仍需重新审查。后台运行不改变游戏服务端规则，浏览器不会执行已被冻结页面的 JavaScript。
