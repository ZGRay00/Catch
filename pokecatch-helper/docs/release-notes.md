# PokéCatch 助手 8.8.0

在游戏的方块首领页导出模拟器 Box，可带入当日首领、口味、方块队、最近战果和场地条件。勾选「附培养资源」可供模拟器按实际库存规划。

- [国内版：从 COS 安装或更新](https://catch-elite-sim-1426994854.cos.ap-guangzhou.myqcloud.com/updates/v1/helper/pokecatch-helper.user.js)
- [全球版：从 GitHub 安装或更新](https://raw.githubusercontent.com/ZGRay00/Catch/main/pokecatch-helper.user.js)

两版使用相同脚本身份和业务代码。「在线更新」会从首选渠道读取正式发行签名，在备用源可用时沿该源安装。切换脚本管理器的原生更新渠道时，先导出设置，在原脚本仍安装的情况下打开目标链接，核对名称及来源，确认覆盖，然后刷新游戏。脚本管理器自行决定同版本覆盖提示。管理器的自动更新遵循已安装的 updateURL，脚本运行时的签名检查适用于面板内的检查。
