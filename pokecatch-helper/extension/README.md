# 可选保持激活扩展

本扩展为本项目从头编写的第一方可选支持组件，默认关闭。安装助手无需安装它。

## 安装与使用

1. 在 Chrome 或 Edge 的扩展程序管理页开启“开发者模式”。
2. 选择“加载已解压的扩展程序”，选中含 `manifest.json` 的这个 `extension` 文件夹。
3. 已打开的游戏页请手动刷新一次，使 `document_start` 内容脚本生效。
4. 点击扩展图标，开启“启用后台支持”。需要防止系统休眠时再单独勾选第二项。

支持 `https://pokecatch-online.app/`、`https://pokecatch-online.netlify.app/` 和 `https://pokecatch-online.pages.dev/`。扩展不会刷新游戏、主动登录、调整游戏捕获率/随机数/速度、切换页面焦点或控制其他站点。

## 工作方式

- 隔离世界内容脚本每 20 秒更新本地心跳，同时提供浏览器实际可见性。禁用和离开页面时清除标记。游戏页的 `Document.hidden`、`visibilityState` 仅在本地心跳 90 秒内有效时返回前台状态。
- 自 1.1.0 起，启用后会观察游戏新建的 Supabase Realtime 连接。助手可显示连接中、已连接、客户端主动关闭、正常关闭或异常关闭。状态只含枚举、时间和近期异常次数。地址、凭据、消息内容、关闭原因字符串均不保存。支持开启前已经建立的连接显示“尚未观察到”。关闭支持时撤销构造器代理与监听，已有连接继续由游戏管理。
- 当浏览器明确断网，主助手会保留检查点并等待联网。恢复后先让游戏自行连接。主助手中的“自动恢复”需单独开启，并须启用刷新续跑。符合多项证据时先核对任务、检查点与后台保护，再由主助手刷新；同一标签页至少间隔 10 分钟，每小时至多 2 次。
- 游戏标签页启用期间设置 `autoDiscardable: false`，首次托管前会保存原值；关闭或导航离开游戏站点时恢复原值。默认关闭且从未托管的标签页不会被改动；恢复失败时保留记录并重试。浏览器仍可强制冻结、卸载或终止页面。
- `storage` 保存两个开关与已管理标签页编号；`tabs` 限定查询和调整游戏标签页的自动丢弃设置；`alarms` 用于服务工作线程定期核对。
- `power` 是可选权限，只有用户明确勾选“防止系统自动休眠”时才申请。启用后台支持且获得授权时使用 `system` 级唤醒，关闭即释放。不会要求屏幕保持点亮。

扩展无法保证电脑关机/休眠、断网或浏览器强制冻结时持续运行，也不会制造游戏原生离线时间。游戏是否正常结算仍以游戏自身机制为准。请在长时间挂机前检查设备电源与网络；不需要时可关闭扩展支持。

## 测试

在上级工程执行 `npm run test:build`，会包含 manifest、条件 getter、心跳关闭、标签页恢复和可选 power 的隔离 VM 测试。测试不打开真实用户浏览器，不读取或操作游戏个人存档。
