PokéCatch 保持激活 v1.0.1（2026-11-24 本地优化，未发布）

安装（Chrome 118 及以上）
1. 地址栏打开 chrome://extensions 。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本文件所在的 pokecatch-keep-active 文件夹。
4. 在工具栏的拼图菜单里，将“PokéCatch 保持激活”固定到工具栏。

使用
1. 进入受支持的游戏页面，先关闭游戏页的 F12。
   仅支持以下精确 HTTPS 域名（不支持任意子域名或仿冒后缀）：
   https://pokecatch-online.app/
   https://pokecatch-online.netlify.app/
   https://pokecatch-online.pages.dev/
   域名列表只代表本地兼容配置，本次未联网确认站点可用性或归属。
2. 点击扩展图标，再点击“在当前游戏页开启”。看到绿色 ON 即已开启。
3. 可以切换标签页、最小化整个窗口；电脑仍须保持运行，不能睡眠。
4. 不需要一直打开扩展弹窗或 F12。启用时手动刷新游戏后会尝试恢复；扩展不会自动刷新游戏。
5. 扩展记住启用偏好，浏览器重启后会尝试恢复到一个已打开的游戏标签页。
6. 需要停止时，点击扩展图标，点击“关闭保持激活”。

更新及按钮灰色排查
- 替换文件后，在 chrome://extensions 找到本扩展，手动点击“重新加载”。
  新增站点后请检查 Chrome 的站点访问权限，再切回游戏页并重新打开弹窗。
- 弹窗明确显示支持域名及未识别原因；地址缺失也可能是站点权限未授予，不一定是游戏域名错误。
- “重新检查”只重新读取当前标签页和扩展状态，不会刷新游戏，也不会重新开启已取消的连接。
- 操作进行中按钮暂时禁用，重复点击不重复发请求。出错后可重新检查或关闭保持激活。
- 点击浏览器“取消”后不会自动抢回连接，即使取消前已排队刷新或开启；必须重新手动开启。
- 存储临时读取失败可重试；若存储写入持续失败，当前线程仍尽力停止连接，
  但无法保证关闭偏好跨线程/浏览器重启保存。可在 Chrome 扩展页停用扩展以确保停止。

限制与提示
- 一次只保持一个游戏标签页，不绕过游戏自身的多窗口互斥。切换保持对象时会先停止旧页面。
- 浏览器会显示“此扩展正在调试浏览器/页面”等提示，这是此 API 的正常表现。
- 点击浏览器调试提示的“取消”，或打开游戏页的 F12，可能中断扩展连接。
  此时不会强行抢回连接。请先关闭 F12，再点击扩展手动开启。
- 这是浏览器原生模拟聚焦，不是把 F12 的勾选永久写入游戏。
- 只为游戏域名调用 Emulation.setFocusEmulationEnabled，不注入页面脚本，
  不改游戏速度、时间、存档、资源，不执行点击或向游戏接口提交操作。
- 需要 debugger 权限，所以安装时 Chrome 会显示较宽的调试权限提示；实现只接受本扩展弹窗控制，
  仅连接上述游戏域名，不读取账号令牌、不包含联网代码。
- 游戏对这种后台保持方式是否允许尚未确认，不能保证不会被限制或封禁。
- 本地测试页验证不等于实际游戏、电脑睡眠或浏览器长时间冻结情况下的保证。
